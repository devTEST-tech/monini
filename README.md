# Бот записи на маникюр (Telegram)

Что умеет бот:
- 📅 записывает клиента: услуга → дата → время → имя → телефон;
- у каждой услуги своя длительность (маникюр 1 ч, наращивание 3 ч и т.д.), бот сам блокирует нужное время;
- между клиентами автоматический перерыв (по умолчанию 15 минут);
- ⏰ присылает клиенту напоминание за сутки до визита с кнопкой «Отменить запись»;
- клиент может отменить запись сам, но не позднее чем за 3 часа до визита (дальше только по телефону);
- 🔔 мастеру приходят уведомления о новых записях и отменах;
- ➕ мастер сам добавляет свободные окна прямо в Telegram (см. раздел ниже);
- `/today` показывает мастеру записи на сегодня, `/bookings` показывает все предстоящие;
- 💰 цены, ❓ частые вопросы, 📍 контакты, 📋 «Мои записи».

Все записи хранятся в файле `manicure.db` рядом с ботом.

> **Важно:** бот присылает напоминания и принимает записи, только пока он запущен. Для работы без выходных его нужно запустить на сервере (см. ниже).

## Шаг 1. Создайте бота в Telegram

1. В Telegram найдите **@BotFather** и нажмите «Запустить».
2. Отправьте команду `/newbot`.
3. Придумайте название (например, «Маникюр Анна») и имя пользователя, оканчивающееся на `bot` (например, `anna_nails_bot`).
4. BotFather пришлёт **токен**, длинную строку вида `123456789:AAH...`. Скопируйте её и никому не показывайте.

## Шаг 2. Установите Python

1. Скачайте Python 3.10 или новее с python.org.
2. **Windows:** при установке поставьте галочку **«Add Python to PATH»**.
3. Проверьте в терминале (Windows: `cmd`, Mac: «Терминал»): `python --version`. На Mac может понадобиться `python3`.

## Шаг 3. Подготовьте проект

1. Распакуйте архив в папку `manicure-bot`.
2. Скопируйте файл `.env.example` и назовите копию `.env` (точка в начале обязательна).
3. Откройте `.env` в Блокноте и впишите токен:
   ```
   BOT_TOKEN=123456789:AAH...ваш_токен
   ```
4. Если мастер живёт не в московском часовом поясе, измените `TIMEZONE`, например `Asia/Yekaterinburg` или `Asia/Novosibirsk`.

## Шаг 4. Запустите

Откройте терминал в папке проекта и выполните по очереди (Windows):

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

Mac / Linux:

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 bot.py
```

Когда в терминале появится «Бот запущен», откройте бота в Telegram, нажмите `/start` и сделайте тестовую запись. Остановить бота: `Ctrl + C`.

## Шаг 5. Включите уведомления мастеру

1. Напишите боту команду `/id`. Он ответит вашим Telegram ID (число).
2. Впишите его в `.env`: `ADMIN_IDS=123456789`. Для нескольких получателей перечислите ID через запятую.
3. Остановите бота (`Ctrl + C`) и запустите снова.

> Мастер должен хотя бы раз нажать `/start` у бота, иначе Telegram не даст боту написать ему.

## Свободные окна: как мастеру добавлять время в Telegram

Когда у мастера появилось свободное время (отменилась запись, нужно выйти в выходной, хочется принять вечером), оно добавляется в пару нажатий. Для этого мастер должен быть вписан в `ADMIN_IDS` (шаг 5).

**Добавить окно:**
1. Откройте бота. У мастера в меню есть кнопки **«➕ Добавить окно»** и **«🗓 Открытые окна»** (если их нет, нажмите `/start`).
2. Нажмите «➕ Добавить окно» и выберите дату.
3. Напишите время сообщением, например: `15:00-18:00`.
   Несколько окон сразу пишите через запятую: `10:00-12:00, 15:00-18:00`.
4. Бот ответит «✅ Окно добавлено». Клиенты сразу видят это время при записи.

**Посмотреть и удалить окна:** кнопка «🗓 Открытые окна» (или команда `/windows`) показывает добавленные вами окна, у каждого есть кнопка «🗑 Удалить окно». Уже сделанные записи при удалении окна остаются в силе.

**Два режима работы** (переменная `OPEN_ONLY_BY_ADMIN` в блоке настроек):
- `False` (по умолчанию): клиенты видят обычный график (`WORK_START`–`WORK_END` в рабочие дни) **плюс** окна, которые добавил мастер. Подходит, чтобы открывать время в выходные или вечером.
- `True`: клиенты видят **только** окна, которые мастер открыл в боте. Подходит, если мастер сам решает, когда принимает. Если окон нет, клиент увидит «нет свободных дат».

Бот сам нарежет окно на время начала с шагом `SLOT_STEP_MINUTES` и учтёт длительность услуги и перерыв между клиентами. Например, окно `14:00-18:00` для услуги на 3 часа даёт начало записи в 14:00, 14:30 и 15:00.

## Как настроить под мастера

Откройте `bot.py` в Блокноте (или VS Code) и найдите блок **«НАСТРОЙКИ МАСТЕРА»** в начале файла. Меняйте только его. Все цены и тексты в нём примерные.

| Что | Переменная |
|---|---|
| Название студии, имя мастера, телефон, адрес | `BUSINESS_NAME`, `MASTER_NAME`, `MASTER_PHONE`, `ADDRESS` |
| Ссылка на работы (VK, Telegram-канал). Если пусто, кнопки нет | `PORTFOLIO_URL` |
| Услуги, цены, длительность | `SERVICES` |
| Рабочее время | `WORK_START`, `WORK_END` |
| Рабочие дни (0 = понедельник, 6 = воскресенье) | `WORK_DAYS` |
| Особые выходные | `DAYS_OFF`, например `["2026-12-31", "2027-01-01"]` |
| На сколько дней вперёд запись | `DAYS_AHEAD` |
| Режим окон: обычный график + окна мастера или только окна мастера | `OPEN_ONLY_BY_ADMIN` |
| Шаг времени (30 мин: 10:00, 10:30...) | `SLOT_STEP_MINUTES` |
| Перерыв между клиентами | `BUFFER_MINUTES` |
| Запись не ближе чем за (минут) | `MIN_NOTICE_MINUTES` |
| Отмена онлайн не позднее чем за (часов) | `CANCEL_BEFORE_HOURS` |
| Напоминание за (часов) | `REMINDER_HOURS` |
| Частые вопросы | `FAQ` |

Как добавить услугу: скопируйте любую строку в `SERVICES`, поменяйте `id` (любое новое слово латиницей), название, цену и `minutes` (длительность в минутах).

После любых правок остановите бота (`Ctrl + C`) и запустите снова.

## Запуск на сервере 24/7 (Linux, VPS)

1. Загрузите папку проекта на сервер, например в `/opt/manicure-bot`.
2. На сервере выполните:
   ```
   cd /opt/manicure-bot
   python3 -m venv venv
   venv/bin/pip install -r requirements.txt
   ```
3. Создайте файл `/etc/systemd/system/manicure-bot.service`:
   ```
   [Unit]
   Description=Telegram manicure booking bot
   After=network.target

   [Service]
   WorkingDirectory=/opt/manicure-bot
   ExecStart=/opt/manicure-bot/venv/bin/python bot.py
   Restart=always

   [Install]
   WantedBy=multi-user.target
   ```
4. Включите и запустите:
   ```
   sudo systemctl daemon-reload
   sudo systemctl enable --now manicure-bot
   ```
5. Журнал: `sudo journalctl -u manicure-bot -f`. Перезапуск после правок: `sudo systemctl restart manicure-bot`.

Раз в неделю копируйте файл `manicure.db`: это резервная копия записей.

**Про доступ к Telegram.** Если у вас на компьютере Telegram работает только через VPN, запускайте бота с включённым VPN. Или впишите в `.env` адрес прокси: `PROXY_URL=socks5://127.0.0.1:1080`. Сервер за пределами РФ избавляет сам бот от этой проблемы, но клиентам по-прежнему нужен доступ к Telegram.

## Частые ошибки

| Сообщение | Что делать |
|---|---|
| `Не найден BOT_TOKEN` | Файл называется именно `.env` (не `.env.example` и не `.env.txt`), токен вписан после `BOT_TOKEN=` |
| `Unauthorized` | Токен скопирован неверно. Возьмите новый в @BotFather командой `/token` |
| `Cannot connect to host api.telegram.org` | Нет доступа к Telegram. Включите VPN или укажите `PROXY_URL` |
| `python не найден` | Python не добавлен в PATH. Переустановите с галочкой «Add Python to PATH» |
| Мастеру не приходят уведомления | Проверьте `ADMIN_IDS` и нажмите `/start` у бота с аккаунта мастера |
| Клиент не получил напоминание | Бот должен быть запущен в это время. Проверьте, что он работает на сервере 24/7 |
| Любая другая ошибка | Скопируйте последние 10–15 строк из терминала и отправьте мне |
